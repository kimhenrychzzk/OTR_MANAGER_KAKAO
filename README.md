# OTR MANAGER — 카카오톡 채널 AI 챗봇

## 포함 기능
- 카카오 챗봇 스킬 API 형식(`version: 2.0`)의 응답
- 규칙 / 지역 / 모임 / 출석 / 소개: 키워드별 즉시 답변
- 그 밖의 질문: OpenAI API를 이용한 한국어 AI 응답(선택 사항)
- AI API 키가 없어도 FAQ 작동
- 회원 정보 저장 없음

## 1. 로컬 실행
Node.js 18 이상 설치 후 폴더에서 `npm start` 실행. 브라우저에서 `http://localhost:3000/health`를 열면 상태를 확인할 수 있습니다.

## 2. 인터넷 서버에 배포
Render, Railway 등 Node.js 웹 서비스 호스팅에 이 폴더를 업로드/연결합니다. 시작 명령: `npm start`. 필요한 경우 환경 변수 `OPENAI_API_KEY`를 **서버 설정 화면**에 입력합니다. 키를 코드나 공개 저장소에 넣지 마세요. 서비스 URL은 HTTPS여야 합니다.

## 3. 카카오 챗봇 관리자센터에서 스킬 등록
1. OTR MANAGER 봇을 열고 왼쪽 **스킬** 메뉴 선택.
2. **스킬 생성**을 눌러 이름을 `OTR AI 응답`으로 설정.
3. URL에 `https://배포한-서버-주소/skill` 입력 후 저장.
4. **시나리오**에서 `OTR AI 대화` 블록 생성. 사용자 발화 예: `안녕`, `오늘 뭐해?`.
5. 블록의 **파라미터 설정 → 스킬 검색/선택**에서 등록한 `OTR AI 응답` 스킬을 연결하고 저장.
6. **봇테스트**에서 호출을 확인하고 배포.
7. **설정**에서 카카오톡 채널 연결을 완료해야 실제 카카오톡 채널에서 이용할 수 있습니다.

**중요:** 모든 자유 입력을 AI로 보내려면 챗봇 관리자센터의 **폴백 블록**에도 같은 스킬을 연결하는 것이 일반적입니다. 블록/폴백에 스킬을 연결하는 메뉴명은 관리자센터 버전에 따라 달라질 수 있습니다.

## 4. 웰컴 블록 텍스트 (복사해 등록)
안녕! 나는 OFF THE RECORD의 AI 매니저 OTR이야 😎🖤

중랑·동대문·광진·성동을 중심으로 편하게 이야기 나누는 커뮤니티야!

궁금한 건 언제든 물어봐. 규칙, 지역, 모임 안내도 도와줄게!

## 5. 테스트 예시
```bash
curl -X POST http://localhost:3000/skill -H 'Content-Type: application/json' -d '{"userRequest":{"utterance":"모임은 언제야?"}}'
```

## 운영상 제한
- 이 서버는 카카오톡 **채널 1:1 챗봇용**입니다. 오픈채팅방에 참여하지 않습니다.
- 카카오톡 채널에서 먼저 대화를 시작하지 않은 회원에게 매일 자동으로 메시지를 보내는 기능은 구현되어 있지 않습니다. 공식 발송 권한과 정책을 별도로 검토해야 합니다.
- 카카오 스킬 응답 시간 제한 때문에 AI API 호출을 약 3.5초로 제한했습니다. 느린 응답은 안내 메시지로 대체됩니다. 실제 운영 시 공식 콜백 기능 등 별도 설계가 필요할 수 있습니다.
- 예제는 입문용입니다. 공개 운영 전에는 요청 검증, 사용량 제한, 로그 개인정보 최소화, 비용 한도 설정 등을 추가하는 것이 좋습니다.
- 카카오 계정/채널 연결, 서버 배포, API 키 발급은 사용자가 직접 해야 합니다.
